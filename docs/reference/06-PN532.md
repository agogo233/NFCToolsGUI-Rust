# PN532 NFC 控制器参考

> 依据：NXP PN532 数据手册、libnfc `pn53x.c` / `pn532_uart.c` / `pn532_i2c.c` /
> `pn532_spi.h` 源码（已 vendored 于 `framework/source/libnfc`）。
> 本文档是硬件层参考：PN532 与 PC 的接口、帧格式、命令集。
> 本项目经 libnfc 驱动 PN532，应用层（Rust）只接触 libnfc 的抽象接口。

---

## 1. PN532 概述

PN532 是 NXP 的 **13.56 MHz NFC 控制器**，支持：

- **发起者（Initiator）模式**：读卡（本项目主用途）
- **目标（Target）模式**：模拟卡/点对点
- **ISO/IEC 14443 A/B**、**ISO/IEC 18092**（FeliCa、NFC-DEP）、**ISO/IEC 15693**（ICODE）

与主机的接口有三种，libnfc 支持全部：

| 接口 | libnfc 驱动 | 说明 |
|---|---|---|
| **UART（HSU）** | `pn532_uart` | RS232/串口，默认 **115200 波特** |
| SPI | `pn532_spi` | 高速同步 |
| I²C | `pn532_i2c` | 双线 |

> 本项目 `serial.rs` 用 `serialport` 枚举串口，通过 **UART（HSU）** 与 PN532 通信。
> 连接时写 `libnfc.conf`（`device = pn532_uart:COMx:115200`）。

## 2. UART（HSU）帧格式

PN532 UART 通信帧（**小端**，LSB 先）：

### 2.1 正常帧（Normal Frame）

```
前置:   00 00 FF          ← 唤醒/起始码
LEN:    <n+1>             ← 数据长度 = DATA 字节数 + 1（DCS），不含 TFI
LCS:    <256 - LEN>       ← LEN 补码校验（(256-LEN)&0xFF）
TFI:    D4                ← 主机→PN532 命令帧标识（读响应为 D5）
DATA:   <命令码 + 参数>    ← 命令负载（n 字节）
DCS:    <256 - D4 - ΣDATA> ← 数据校验和
后置:   00                ← 结束标记
```

| 字段 | 值 | 说明 |
|---|---|---|
| Preamble | `00 00 FF` | 起始序列 |
| LEN | `n+1` | DATA 字节数 + DCS（**不含 TFI**） |
| LCS | `256 - LEN` | LEN 补码校验 |
| TFI | `D4`（命令）/ `D5`（响应） | 帧类型标识 |
| DATA | 命令码 + 参数 | 见 §4 命令集 |
| DCS | `256 - D4 - ΣDATA` | 数据校验和 |
| Postamble | `00` | 结束标记 |

> 源码：`pn53x_build_frame`（`pn53x.c`）：`LEN = szData + 1`（`szData`=DATA 长度）、
> `LCS = 256 - LEN`、`DCS = 256 - D4 - ΣDATA`。
> **ACK 帧** = `00 00 FF 00 FF 00`（`pn53x_ack_frame`），表示 PN532 已接收命令
> （LEN=0、LCS=FF 为特殊硬编码帧）。
> **例**：GetFirmwareVersion（DATA=`[02]`，n=1）→ `00 00 FF 02 FE D4 02 28 00`。

### 2.2 扩展帧（Extended Frame）

当数据 > 正常帧上限（255 B）时：

```
00 00 FF  FF FF  <LENm> <LENl>  <LCS>  D4  <DATA...>  <DCS>  00
```

`LENm`/`LENl` 为 16 位长度（高/低字节），`LCS = 256 - (LENm + LENl)`。

### 2.3 唤醒（Wake-up）

- HSU 唤醒：发送 `55h` 并等待延迟，PN532 从低功耗唤醒。
- 之后发送 `00 00 FF` 前置 + `SAMConfiguration` 命令确认芯片是 PN532。

> 源码：`pn532_uart_wakeup`（发送 `0x55`）。

## 3. 芯片识别（GetFirmwareVersion）

`GetFirmwareVersion`（`02h`）返回 4 字节：`IC 固件Ver 固件Rev 支持能力`。

- `IC = 0x32` → **PN532**（`pn53x.c`：`abtFw[0] == 0x32` 判 PN532）。
- 固件字符串：`"PN532 v%d.%d"`（固件版本、修订）。

> libnfc 打开设备后用 GetFirmwareVersion 设置 `CHIP_DATA(pnd)->type`。
> 本项目 `nfc-list` 输出会含 `PN532 v1.6` 之类信息。

## 4. 命令集（PN53x 通用）

libnfc 使用的 PN53x 命令码（`pn53x-internal.h`）：

| 命令 | 命令码 | 说明 |
|---|---|---|
| **Diagnose** | `00h` | 诊断（通信测试 `00h`） |
| **GetFirmwareVersion** | `02h` | 读固件版本 |
| **SAMConfiguration** | `14h` | 配置 SAM（Security Access Mode） |
| **RFConfiguration** | `32h` | RF 配置 |
| **InListPassiveTarget** | `4Ah` | 被动目标列表（读卡） |
| **InDataExchange** | `40h` | 与目标交换数据 |
| **InCommunicateThru** | `42h` | 透传 |
| **InAutoPoll** | `60h` | 自动轮询（PN532） |
| **TgInitAsTarget** | `8Ch` | 目标模式初始化 |

### 4.1 SAM 模式

`SAMConfiguration`（`14h`）的 mode 参数（`pn53x.h`）：

| 模式 | 值 | 说明 |
|---|---|---|
| PSM_NORMAL | `01h` | 正常（读卡器） |
| PSM_VIRTUAL_CARD | `02h` | 虚拟卡 |
| PSM_WIRED_CARD | `03h` | 有线卡 |
| PSM_DUAL_CARD | `04h` | 双卡 |

> libnfc 打开后默认设 `PSM_NORMAL`。`pn532_initiator_init_secure_element` 设
> `PSM_WIRED_CARD`（安全元件桥接）。

### 4.2 调制类型（用于 InListPassiveTarget）

`pm` 参数（`pn53x.h`）：

| 调制 | 值 |
|---|---|
| PM_ISO14443A_106 | `0x00`（Type A 106 kbit/s） |
| PM_FELICA_424 | `0x02` |
| PM_ISO14443B_106 | `0x03` |
| PM_JEWEL_106 | `0x04` |
